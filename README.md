### 📌 Pinned Projects

* 🤖 <a href="https://github.com/SohithTondepu/RAG_MediBOT" target="_blank"><strong>RAG_MediBOT</strong></a> — Medical RAG Platform engineered with FastAPI, Streamlit, and Groq LLMs. Features dual-stage hybrid retrieval (Pinecone dense embeddings + BM25 sparse search) via Reciprocal Rank Fusion (RRF) and Cross-Encoder reranking.
* 🍽️ <a href="https://github.com/SohithTondepu/ABSA-Dinesense" target="_blank"><strong>ABSA-Dinesense</strong></a> — End-to-end Aspect-Based Sentiment Analysis pipeline evaluated on 10,000+ restaurant reviews with fine-tuned DistilBERT (91.7% test accuracy) and interactive multi-tab Streamlit analytics dashboard.
* ⚙️ <a href="https://github.com/SohithTondepu/Bearing-Fault-detection-in-machines" target="_blank"><strong>Bearing Fault Detection in Machines</strong></a> — 2-channel signal processing & ML pipeline on CWRU dataset extracting synchronous spectral/temporal tensors, achieving 98.0% cross-domain accuracy with noise resilience under SNR decay.
* 🔬 <a href="https://github.com/SohithTondepu/Breast_cancer_prediction" target="_blank"><strong>Breast Cancer Detection & Classification</strong></a> — Diagnostic ML classification pipeline using PCA dimensionality reduction, Linear SVM, and GridSearchCV cross-validation achieving 98% accuracy and 100% precision on malignant tumor detection.
